# 농업 챗봇 데이터 계약

## 과거 데이터 점검

과거 저장소의 `backend/chatbot.csv`는 2026-08-30 기준으로 다시 파싱했다.

- 파싱 가능한 질문·답변: 158건
- 중복 질문: 0건
- 답변에 `출처`, 참고 링크 또는 URL 흔적이 있는 항목: 20건
- 파일 자체의 생성 기관, 배포 페이지, 버전, 라이선스: 확인 불가

대표 문구를 역검색하면 일부는 팜한농 작물보호제 FAQ와 일치하고, 일부는 농촌진흥청
농약안전정보시스템 FAQ와 일치한다. 즉 단일 원천 데이터가 아니라 여러 기관의 문답을
출처 열 없이 합친 파일로 보인다.

- 팜한농 FAQ: https://www.farmhannong.com/kor/cs/faq/often/list.do
- 농촌진흥청 농약안전정보시스템 FAQ: https://psis.rda.go.kr/psis/share/bbs/qnaAjaxLst.ps?bbsId=13

전체 데이터의 원천과 갱신 시점을 검증할 수 없으므로 이 파일과 기존 Chroma 산출물은
공개 저장소 및 운영 인덱스에 복원하지 않는다.

## 신규 원본 CSV

`chatbot_source.example.csv`와 같이 다음 열을 모두 포함해야 한다.

| 열 | 규칙 |
|---|---|
| `질문` | 비어 있지 않은 질문 |
| `답변` | 출처 내용을 정확히 반영한 답변 |
| `출처` | 농촌진흥청 등 원문 제공기관 |
| `출처URL` | 해당 내용을 직접 확인할 수 있는 HTTPS URL |

빈 행은 건너뛰지만 일부 값만 누락된 행과 HTTP URL은 인덱스 생성을 중단한다.

## 인덱스 재현 계약

`build_chatbot_index`는 Chroma DB와 함께 `index-manifest.json`을 만든다. Manifest에는
원본 CSV SHA-256, 문서 수, 임베딩 모델, 컬렉션 이름과 생성 시각을 기록한다. 런타임은
DB 파일만 존재하는 기존 artifact를 사용하지 않으며 현재 설정과 manifest가 일치할 때만
챗봇을 활성화한다.

임베딩 생성과 실시간 답변에는 OpenAI API 비용이 발생하므로 명시적으로 키와 기능 플래그를
설정한 환경에서만 실행한다.
